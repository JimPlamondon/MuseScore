# JiMStaff Milestone 7 — playback: automated sensory evidence

Owner rulings 2026-08-17: a JiMS note sounds what its lattice identity and its section's state (tuning + reference) say; the reference (Re0's MIDI key) is a Kernel fact per staff and per key-change section, always in sync, handed to playback. Kernel op `note_sounding_pitch` (jims PR 211, `main 720b95c`); fork transport at `NominalNoteCtx` construction (`src/engraving/playback/renderingcontext.h`), Kernel MIDI key + cents → `jimsPitchLevelFromMidi` (`pitchutils.h`, owner decision 1a).

## Fixtures (`scores/`)

- `default-12tet-scale.mscx` — one JiMStaff (12-TET, reference pinned Re0 = 62), whole notes C4 D4 E4 F4 G4 A4 B4 C5 (identities (1,−2) (0,0) (−1,2) (2,−3) (1,−1) (0,1) (−1,3) (2,−2)), 120 bpm. Authored from the M6 gate file's header (state) with generated measures.
- `non12tet-17tet-scale.mscx` — the same score with `generator_cents` 705.8823529411765 (17-TET), reference 62.
- `m6-gate.mscz` — the M6 gate file exactly as Jim and Claude left it (sha256 `87fa038b34b045fb…`): bar 1 E4 D4 F4 G4 under base reference 62; bar 2 C5 D5 E5 F5 identities under the bar-2 carrier (reference 53, mode La); bar 3 = bar 1's identities pasted into the reference-53 section.

## Predictions (`kernel-predictions.json`)

Generated by `make_kernel_predictions.py`: it parses each fixture's base staff state and carriers, walks voice-1 notes with their identities and timings (4/4 at the score tempo), and asks the Kernel bridge for every note through `cargo run --release -p jims-musescore-bridge --example request` (jims PR 212) — op `note_sounding_pitch`. Nothing in this directory computes a frequency, key, or cents; the goal's illustrative "295.7 Hz" figure was **not** used anywhere.

## Renders and measurement

- Renders: `mscore -o <name>.wav <score>` from a fresh scratch install of the fork's `build.release` (`cmake --install build.release --prefix <scratch>`; the installed bundle carries `Resources/sound/MS Basic.sf3` — the un-installed build tree renders silence). WAVs are not committed; sha256 (first 16 hex): `default-12tet-scale.wav de3491a6508f6f33`, `m6-gate.wav 73242133046e0432`, `non12tet-17tet-scale.wav f519815456699f2d`, `stock-control.wav e49f65a972d81b93`, pre-fix `m6-gate.wav 2b15784feff3ca98`.
- Analyzer: `verify_frequencies.py` — RIFF/WAVE reader (float32/PCM), mono mix, per-note window skipping attack/release (0.25 s / 0.15 s, proportional for short notes), Hann window, 5-partial Harmonic Product Spectrum fundamental (robust to piano partials), parabolic refinement on the fundamental's own peak; fails on silent/clipped/ambiguous windows.
- **Synth calibration** (`calibrate_synth.py` → `synth-calibration.json`, `synth-calibration.musicxml`): the MS Basic piano's samples are not perfectly tuned — a stock, non-JiMS piano F3 measures −7.05 cents through the same render path (`stock-control.musicxml`), key 53 −5.04 in the whole-note calibration, mean −2.2 cents over MIDI 48–76 (range −5.0 … +0.9). The verifier reports each note's raw error and its error relative to prediction + that key's stock offset; **the 5-cent oracle applies to the calibrated error**, and the raw error is kept beside it in `frequency-results.json`.

## Results

- **Post-fix (`frequency-results.json`): 28/28 pass** — calibrated |error| ≤ 2.4 cents (raw ≤ 5.0); the 12-TET scale calibrates to |error| ≤ 0.5 cents; the reference-53 section (bar 2: 311.13/349.23/392.00/415.31 Hz — Eb4 F4 G4 Ab4) and the pasted bar 3 (196.00/174.61/207.65/233.08 Hz — G3 F3 Ab3 Bb3) and every 17-TET note (e.g. C4 259.85 Hz = −11.76 cents, E4 331.88 = +11.76) measure at the Kernel's predicted frequencies.
- **Pre-fix red receipt (`frequency-results-prefix.json`)**: the pre-M7 installed bundle (`build.install610`, fork `7927013232`) plays bar 1 correctly and bars 2–3 **+900 cents** off the Kernel prediction (their 12-TET compatibility pitches C5 D5 E5 F5 / E4 D4 F4 G4 instead of the section's Eb4 F4 G4 Ab4 / G3 F3 Ab3 Bb3): 8/12 fail.

Scope statement: the acceptance target is MuseScore's internal synthesizer (MS Basic), which honours per-note tuning; MuseSounds/VST/external synth tuning guarantees are out of scope (Non-goals).
